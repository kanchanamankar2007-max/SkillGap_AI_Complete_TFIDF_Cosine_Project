# SkillGap AI – Skill Gap Analysis System

## Project Overview
SkillGap AI is an AI-powered web application designed to help students identify skill gaps based on their desired job roles. It analyzes existing skills against industry requirements and recommends relevant learning resources.

## Features
- User Registration and Login
- Resume and Skill Analysis
- Job Role-Based Skill Matching
- TF-IDF Vectorization
- Cosine Similarity Calculation
- Skill Gap Identification
- Personalized Course Recommendations
- Learner Dashboard
- Admin Dashboard
- Analysis History
- PDF Report Generation

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **Database:** SQLite
- **NLP:** TF-IDF and Cosine Similarity

## Methodology
1. Collect student resume or skill information.
2. Extract skills using NLP techniques.
3. Compare student skills with job-role requirements.
4. Calculate similarity using TF-IDF and Cosine Similarity.
5. Identify matched and missing skills.
6. Recommend relevant courses and learning resources.

## Installation and Setup

1. Clone the repository:
   `git clone https://github.com/kanchanamankar2007-max/SkillGap_AI_Complete_TFIDF_Cosine_Project.git`

2. Navigate to the project folder:
   `cd SkillGap_AI_Complete_TFIDF_Cosine_Project/AI_SKILL_GAP_PROJECT`

3. Install dependencies:
   `pip install -r requirements.txt`

4. Run the application:
   `python app.py`

5. Open the local URL displayed in your terminal.
